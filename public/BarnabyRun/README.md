# Barnaby Word Run

Красочная 3D-игра для тренировки английского времени Present Continuous. Игрок управляет капибарой Барнаби, собирает золотые жёлуди и составляет предложения по картинкам.

На трассе встречаются редкие объёмные сердца: они восстанавливают одну из пяти жизней и появляются только тогда, когда Барнаби требуется лечение.

## Управление

- Компьютер: стрелки `←` и `→` — смена полосы, стрелка `↑` или `Пробел` — прыжок.
- Телефон и планшет: сенсорные стрелки слева, кнопка прыжка справа; также поддерживаются свайпы.
- Пауза включается и снимается только верхней кнопкой паузы.

## Локальный запуск

Готовую игру можно открыть напрямую через `index.html`.

Для пересборки исходного кода нужен Node.js 20+ и pnpm:

```bash
pnpm install
pnpm run release
```

Команда создаст проверенную папку `dist` со всеми файлами для публикации.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub и загрузите в него содержимое этой папки.
2. В настройках репозитория откройте **Settings → Pages**.
3. В пункте **Source** выберите **GitHub Actions**.
4. Отправьте изменения в ветку `main` — готовая настройка автоматически соберёт и опубликует игру.

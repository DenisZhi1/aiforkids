# Warm-up Deck

Интерактивная разговорная игра для разминки на уроках английского. В колоде 160 уникальных карточек: по 40 вопросов для уровней A1, A2, B1 и B2.

Игра работает без установки и внешних библиотек. Поддерживаются компьютеры, Android-смартфоны, iPhone и планшеты.

## Запуск

Откройте `index.html` в браузере.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий GitHub.
2. Загрузите в его корень всё содержимое этой папки, включая `.github` и `scripts`.
3. Используйте ветку `main`.
4. Откройте **Settings → Pages**.
5. В разделе **Build and deployment** выберите **GitHub Actions**.

После загрузки GitHub автоматически проверит карточки и опубликует игру. Каждое следующее обновление ветки `main` будет проходить такую же проверку и автоматически появляться на сайте.

## Состав проекта

- `index.html` — страница игры;
- `styles.css` — оформление и адаптация под разные экраны;
- `questions.js` — 160 карточек;
- `game.js` — игровая логика;
- `favicon-32.png`, `favicon-192.png`, `apple-touch-icon.png` — иконки для браузеров и мобильных устройств;
- `.github/workflows/pages.yml` — автоматическая публикация;
- `scripts/validate.mjs` — проверка проекта перед публикацией.

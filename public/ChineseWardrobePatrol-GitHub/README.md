# Chinese Words: Wardrobe Patrol

Космическая HTML-игра для детей, изучающих китайские слова по теме одежды, действий и самостоятельности.

Слова в игре: `衣服`, `衬衫`, `鞋`, `穿`, `穿上`, `脱下`, `能`, `帮助`, `帮`, `自己`.

## Как играть

1. Прочитайте русскую подсказку и рассмотрите картинку.
2. Найдите астероид с правильным китайским словом.
3. Переместите Зиби стрелками `↑` / `↓` или клавишами `W` / `S`.
4. Нажмите `Space`, `Enter` или кнопку **FIRE**.
5. Пройдите 12 заданий и сохраните щит.

После правильного попадания игра показывает пиньинь и перевод, а при доступном китайском голосе браузера произносит слово.

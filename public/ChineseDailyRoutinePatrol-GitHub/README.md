# Chinese Words: Daily Routine Patrol

Самостоятельная HTML-игра для тренировки китайских слов по теме распорядка дня, еды, школы и времени суток.

## Что внутри

- 15 слов и выражений: 吃, 饭, 起, 床, 起床, 去, 上学, 去上学, 早饭, 晚饭, 早上, 上午, 中午, 下午, 晚上;
- 45 вопросов — по три формулировки для каждого слова;
- 15 заданий в миссии — каждое слово встречается ровно один раз;
- мультяшные иллюстрации, пиньинь, перевод и произношение правильного ответа;
- управление стрелками, пробелом, мышью или экранными кнопками;
- музыка, звуковые эффекты, регулировка громкости, щит и комбо.

## Как запустить

Откройте `index.html` в браузере. Интернет и установка программ не нужны.

## Как опубликовать на GitHub Pages

1. Загрузите **содержимое этой папки** в корень репозитория.
2. Откройте `Settings` → `Pages`.
3. В разделе `Build and deployment` выберите `Deploy from a branch`.
4. Выберите ветку `main`, папку `/ (root)` и нажмите `Save`.

Главный файл `index.html` уже находится в корне, а все ресурсы подключены относительными путями.

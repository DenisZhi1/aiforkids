# Barnaby Word Run

Красочная образовательная 3D-игра для тренировки английского времени **Present Continuous**. Игрок управляет капибарой Барнаби, собирает золотые жёлуди и составляет предложения по картинкам.

## Что есть в игре

- 16 разных заданий за один забег — картинки и предложения не повторяются.
- Случайный порядок заданий при каждом новом запуске.
- Пять жизней и редкие объёмные сердца для восстановления здоровья.
- Золотые жёлуди, временное ускорение от гриба и лист-магнит.
- Постоянная базовая скорость Барнаби без автоматического ускорения.
- Итоговый экран с именем ученика и просмотром допущенных ошибок.
- Управление и адаптивный интерфейс для компьютеров, телефонов и планшетов.

## Управление

- Компьютер: стрелки `←` и `→` — смена полосы, стрелка `↑` или `Пробел` — прыжок.
- Телефон и планшет: сенсорные стрелки слева, кнопка прыжка справа; также поддерживаются свайпы.
- Пауза включается и снимается только верхней кнопкой паузы.

## Локальный запуск

Готовую игру можно открыть напрямую через `index.html`. Интернет для запуска не требуется.

Для пересборки исходного кода нужен Node.js 20+ и pnpm:

```bash
pnpm install
pnpm run release
```

Команда создаст проверенную папку `dist` со всеми файлами для публикации. Папка не хранится в Git и пересобирается автоматически.

## Проверка релиза

```bash
pnpm run verify
```

Проверка контролирует наличие ресурсов, регистр имён файлов, формат 3D-моделей и общий размер публикации.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub и загрузите в него содержимое этой папки.
2. В настройках репозитория откройте **Settings → Pages**.
3. В пункте **Source** выберите **GitHub Actions**.
4. Отправьте изменения в ветку `main` — готовая настройка автоматически соберёт и опубликует игру.
